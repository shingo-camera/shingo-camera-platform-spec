# ADR-001 AUTH_USER_IDを共通ユーザーキーとして採用

Status: Approved

## 決定

Supabase Authが発行するAUTH_USER_IDを、M_USERおよび関連テーブルのユーザーキーとして使用する。

自前の連番USER_IDは持たない。

## 理由

- 認証基盤との紐付けが直接的
- 採番処理が不要
- メールアドレス変更時も関連データが維持される
- 想定規模では人向け連番IDの利点がない
- 管理画面はメールアドレスを主に使用する

## 影響

全ユーザー関連テーブルはAUTH_USER_IDで結合する。

AUTH_USER_IDは通常画面へ表示しない。
