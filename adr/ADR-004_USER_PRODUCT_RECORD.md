# ADR-004 商品権限を1ユーザー×1商品のレコードで管理

Status: Approved

## 決定

ユーザーの商品保有状態をM_USERのフラグ列ではなく、T_USER_PRODUCTで管理する。

主キー:

```text
AUTH_USER_ID + PRODUCT_ID
```

## 理由

- 商品追加時にDBカラム変更が不要
- 3商品保有なら3レコードという直感的な構造
- 有効期間、停止、付与理由を商品単位で管理できる
- HANABI、Google Earth、SUN AND MOONを同じ仕組みで扱える

## 再付与

既存レコードを更新・復活させる。

同一ユーザー・同一商品の権限レコードを複数作らない。
