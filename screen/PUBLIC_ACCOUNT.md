# Public and Account Screen Design

Status: Approved

## 1. デザイン方針

- 写真家のポートフォリオにしない
- 受賞歴を出さない
- フォロワー数を出さない
- 開発者紹介を前面に出さない
- 華美にしない
- 道具・製品のサイトとして見せる
- アプリ画面と実写結果を中心にする
- SNSリンクがあれば十分
- 白または落ち着いた明るい背景
- 見やすさ、速さ、迷わなさを優先

## 2. ナビゲーション

```text
HOME
PRODUCTS
SUPPORT
LOGIN
```

ログイン後:

```text
HOME
ACCOUNT
SUPPORT
LOGOUT
```

## 3. 公開トップ

### Header

- shingo_camera
- PRODUCTS
- SUPPORT
- LOGIN

### Hero

短いメッセージ。

例:

```text
撮影計画を、もっと正確に。
```

説明文は最小限。

### Products

商品カード:

- SUN AND MOON PLANNER
- HANABI PLANNER

各カード:

- アプリ画面
- 何ができるか
- 詳細ボタン

### 実例

```text
アプリ上の計画
↓
実際に撮影できた写真
```

を2〜3例。

### Footer

- Instagram
- X
- YouTube
- note
- 利用規約
- プライバシーポリシー
- 特商法表記
- お問い合わせ

プロフィール・受賞歴は置かない。

## 4. ログイン

- メールアドレス
- パスワード
- ログイン
- 新規登録
- パスワードを忘れた方

初期はGoogleログインを必須としない。

## 5. 新規登録

- メールアドレス
- パスワード
- パスワード確認
- 利用規約同意
- 登録ボタン

登録後はメール認証案内を表示する。

## 6. ログイン後ホーム

ランチャー形式。

### 利用可能

保有商品カードを表示。

カード押下でアプリ起動。

### 未購入

購入可能商品を表示。

購入済みと未購入を明確に分ける。

### 既存HANABI購入者

note移行導線を表示する。

## 7. アカウント

- メールアドレス
- パスワード変更
- パスワード再設定
- 保有商品
- 購入履歴
- note移行状況
- ログアウト

氏名、住所、電話番号、プロフィールは持たない。

## 8. 購入完了

表示:

```text
購入ありがとうございます。
購入情報を確認しています。
```

Webhook反映確認後:

```text
利用を開始できます。
```

反映待ちの場合は再確認ボタンを表示する。

完了画面から権限を直接付与しない。
