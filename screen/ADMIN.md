# Admin Screen Design

Status: Approved

## 1. 方針

- PC専用
- 一覧性重視
- 華美なデザイン不要
- 操作はボタン1つを基本
- 破壊的操作のみ確認ダイアログ
- SQL直接更新を避ける

## 2. 画面一覧

```text
/admin
/admin/users
/admin/users/{authUserId}
/admin/warnings
/admin/note
/admin/products
```

## 3. ダッシュボード

上部:

- 総ユーザー数
- 商品別利用者数
- 当日新規登録
- 当日購入
- note未移行
- 未対応Warning

下部:

- 直近Warning一覧
- 対象ユーザー詳細リンク

Warningがない場合は「要確認なし」と表示する。

## 4. ユーザー一覧

検索:

- メールアドレス部分一致
- STATUS
- 保有商品

一覧:

- メールアドレス
- 状態
- 保有商品
- 登録日時
- 最終ログイン
- 最終アクセス
- 詳細ボタン

- 付与

### 購入履歴

- 購入日時

## 6. Warning対応

メール通知のリンクからユーザー詳細へ遷移する。

管理者が時系列ログを確認し、以下を選ぶ。

- 確認済み
- ユーザー確認中
- 除外
- ユーザー停止

自動停止はしない。

## 7. note移行管理

- CSVアップロード
- 取込結果表示
- 未移行一覧
- 移行済一覧
- 要確認一覧
- NOTE_ID検索
- 取引ID検索
- 商品検索
- 手動紐付け
- 紐付け解除
- 無効化

## 8. 商品管理

初期機能:

- 商品一覧
- 商品名編集
- 表示順編集
- 有効・停止

価格・Stripe Price IDの管理方法は秘密情報と公開情報を分けて実装する。
