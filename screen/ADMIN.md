# Admin Screen Design

Status: Approved

## 1. 方針

- PC専用
- 一覧性重視
- 華美なデザイン不要
- 操作はボタン1つを基本
- 破壊的操作のみ確認ダイアログ
- SQL直接更新を避ける

## 2. 画面一覧

```text
/admin
/admin/users
/admin/users/{authUserId}
/admin/warnings
/admin/note
/admin/products
```

## 6. Warning対応

メール通知のリンクからユーザー詳細へ遷移する。

管理者が時系列ログを確認し、以下を選ぶ。

- 確認済み
- ユーザー確認中
- 除外
- ユーザー停止

自動停止はしない。

### WORK-006 実装範囲

- WORK-006 では Warning の一覧・絞込・手動の状態/MEMO 更新までを実装する。
  状態更新時は LAST_ACTION_DATE / UPDATE_DATE を更新する。
- ユーザー停止が必要な場合はユーザー状態 API を別途実行する
  （Warning 更新 API からの自動停止はしない）。
- Warning の自動生成・スコア計算・メール通知・ユーザー自動停止は**後続 WORK**へ残す。

## 7. note移行管理

- CSVアップロード
- 取込結果表示
- 未移行一覧
- 移行済一覧
- 要確認一覧
- NOTE_ID検索
- 取引ID検索
- 商品検索
- 手動紐付け
- 紐付け解除
- 無効化

### WORK-006 実装範囲

- WORK-006 では、ユーザー詳細での note 移行**履歴表示のみ**を実装する。
- CSV 取込・自動マッチング・手動紐付け・紐付け解除・無効化・移行状態変更、
  および T_PURCHASE / T_USER_PRODUCT の生成は**後続 WORK（note 移行）**へ残す。

## 8. 商品管理

初期機能:

- 商品一覧
- 商品名編集
- 表示順編集
- 有効・停止

価格・Stripe Price IDの管理方法は秘密情報と公開情報を分けて実装する。

### WORK-006 実装範囲

- WORK-006 では商品一覧の**閲覧のみ**を実装する。
- 商品名編集・表示順編集・有効/停止は**未実装**（対応する管理 API が正本未定義のため）。
  商品編集を正式に行う場合は、先に ADMIN_API.md へ更新 API を定義する。
